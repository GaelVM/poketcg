Pokémon TCG Pocket
Data API

API JSON pública y ligera para consultar cartas, expansiones, rarezas y metadatos de Pokémon TCG Pocket. Diseñada para integraciones web, herramientas de búsqueda y proyectos relacionados con el juego.

Endpoints disponibles

Todos los endpoints retornan información en formato JSON y pueden consumirse directamente desde aplicaciones web.

Dataset completo normalizado con las cartas disponibles en la API.

Expansiones

Índice de búsqueda

/v1/search-index.json

Versión optimizada del catálogo para implementar buscadores rápidos.

Metadatos
GET
/v1/metadata.json

Estado, versión, última actualización y estadísticas generales de la API.

Quick start

Consumir la API

No requiere autenticación para consultas públicas.

JavaScript · Fetch API 
const API = "https://gaelvm.github.io/poketcg/v1";

async function getCards() {
    const response = await fetch(
        `${API}/cards.json`
    );

    if (!response.ok) {
        throw new Error("API request failed");
    }

    const cards = await response.json();

    console.log(cards);
}

getCards();
